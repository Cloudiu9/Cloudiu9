## Featured project: MovieFlix

<a href="https://disertatie-frontend.vercel.app/">
  <img src="./assets/movieflix.png" alt="MovieFlix home page with a featured movie banner and a row of titles" width="100%">
</a>

A full-stack movie and TV recommendation platform and my Master's dissertation.

- **4,000+ titles** (2,700 movies, 1,500 TV shows)
- **Hybrid recommendation engine:** content-based and collaborative filtering (scikit-learn), designed to solve the cold-start problem for new users
- **AI-generated explanations** and a conversational discovery interface
- **JWT authentication** and decoupled hosting (Vercel + Render) with cross-origin auth configured
- **Stack:** React, TypeScript, Tailwind CSS, Flask, MongoDB Atlas

[Live demo](https://disertatie-frontend.vercel.app/) · [Source code](https://github.com/Cloudiu9/Disertatie)
*(The backend runs on free hosting and may take ~50 seconds to wake up.)*
